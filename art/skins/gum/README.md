# gum — a recolour

Bubblegum: pink with sprinkles scattered over it, an ice-cream BOG.
From `assets/source/skins/GUM/GUM.glb`, the BOG sculpt retextured by Tripo on
that prompt and downloaded with the texture embedded.
Extracted by `python tools/extract_skins.py`: the material's base colour
image, Tripo's 4096² JPEG, downsampled to 2048² and written as PNG.
