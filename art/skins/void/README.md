# void — a recolour

The cosmos: deep purple with nebulae and stars burning across the skin.
From `assets/source/skins/VOID/VOID.glb`, the BOG sculpt retextured by Tripo on
that prompt and downloaded with the texture embedded.

image, Tripo's 4096² JPEG, downsampled to 2048² and written as PNG.
